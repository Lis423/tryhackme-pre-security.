
# Windows Basics

**Plataforma:** TryHackMe  
**Trilha:** Pre Security  
**Status:** Concluído

## Objetivo

Compreender o funcionamento do sistema operacional Windows, sua interface, ferramentas nativas e os recursos utilizados para gerenciar arquivos, usuários, aplicativos e segurança do computador.

## Conteúdos estudados

Fundamentos do sistema operacional Windows.  
Contas de usuários e autenticação.  
Área de trabalho e barra de tarefas.  
Menu Iniciar e ferramenta de pesquisa.  
Explorador de Arquivos.  
Gerenciamento de arquivos e diretórios.  
Instalação, atualização e desinstalação de aplicativos.  
Windows Update e Microsoft Store.  
Configurações do Windows e Painel de Controle.  
Gerenciador de Tarefas.  
Segurança do Windows.  
Firewall do Windows Defender.

## Atividades práticas

Durante o laboratório, utilizei uma máquina virtual Windows Server 2019 Datacenter para:

Consultar informações do sistema operacional.  
Identificar informações do dispositivo.  
Explorar a interface gráfica do Windows.  
Navegar pelo Explorador de Arquivos.  
Instalar e executar um aplicativo.  
Verificar configurações de região e conta de usuário.  
Utilizar o Gerenciador de Tarefas.  
Explorar as ferramentas de segurança do Windows.  
Realizar uma verificação personalizada com o Windows Defender.  
Conhecer as configurações do Firewall do Windows Defender.
