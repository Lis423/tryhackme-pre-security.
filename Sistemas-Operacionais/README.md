# Sistemas Operacionais

**Plataforma:** TryHackMe  
**Trilha:** Pre Security  
**Módulo:** Operating Systems Basics  
**Status:** Concluído

## Objetivo

Compreender o funcionamento dos sistemas operacionais, suas principais funções e a maneira como gerenciam os recursos de um computador, incluindo processos, memória, usuários, dispositivos e arquivos.

## Conteúdos estudados

Fundamentos de sistemas operacionais.  
Kernel Space e User Space.  
Gerenciamento de processos e memória.  
Gerenciamento de usuários e dispositivos.  
Segurança de sistemas operacionais.  
Interface gráfica (GUI).  
Interface de linha de comando (CLI).  
Sistemas de arquivos.  
Fundamentos de Linux.  
Estrutura de diretórios do Linux.

## Atividades práticas

Durante o laboratório, utilizei uma máquina virtual Ubuntu MATE para:

Consultar informações do sistema operacional.  
Identificar informações de hardware.  
Verificar a memória alocada.  
Identificar o sistema de arquivos ext4.  
Explorar diretórios de usuários.  
Navegar entre diretórios do sistema.  
Localizar e consultar arquivos no ambiente Linux.

## Investigação de arquivos

Durante o laboratório, naveguei até o diretório pessoal do usuário Alex e explorei a pasta Documents.

Atividades realizadas:

Navegação entre diretórios do sistema.  
Identificação de arquivos.  
Leitura de arquivo de texto.  
Localização de uma flag utilizando a estrutura de arquivos do Linux.

Arquivo investigado: note.txt

Resultado: Flag encontrada e validada pela plataforma TryHackMe: THM{new_pc_for_free!}
